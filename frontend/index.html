MenstraCare

MenstraCare is a machine-learning based PCOS prediction and model evaluation application. It lets you run custom patient inputs through three trained classification models and review how each model was trained and evaluated.

Accuracy · Precision · Recall · F1 · ROC-AUC

What you can do here

Run a prediction

Enter patient information, choose a model, and get a class prediction with a confidence score.

Switch models

Compare how Logistic Regression, Random Forest and SVM respond to the same input.

Review training results

See the real accuracy, precision, recall, F1 and ROC-AUC scores produced during training.

Inspect model behaviour

Confusion matrices, ROC curves and Random Forest feature importance from the training notebook.

This application is a mini research project. Predictions are generated by machine-learning models for informational / research purposes only and are not a medical diagnosis.
